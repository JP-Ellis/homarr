The Media server streams widget combines active sessions from selected servers. It shows playback progress, resolution,
bitrate, location, and direct-play or transcoding state according to the widget configuration. Advanced view adds search,
sorting, and session metadata.

Healthy integrations remain available when another source fails. Navidrome and Plex return currently playing sessions
rather than every connected session.

### Showing each viewer their own streams

Set **Streams to show** to "Only the viewer" and the widget lists only the signed-in viewer's own sessions. This applies
to integrations that have viewer scoping turned on in their settings; other integrations still show every session. A
viewer without a linked account on the media server sees an empty widget with the note "No linked account".

Once the widget is saved, the saved option decides what the viewer receives. Showing everyone's streams from a
viewer-scoped integration needs interact access to that integration.
